# SHS Music Studio v0.1.0-preview

HOT-Step CPP v1.4.2 기반의 첫 SHS Music Studio 미리보기입니다. 원본의 음악 제작 기능과 라이선스를 유지하고, 다중 사용자 인증, Windows Workspace, 이미지 라이브러리, HTTPS Portable 실행을 추가했습니다.

**상태: 로컬 공개 검토 후보. GitHub Push와 Release 게시를 수행하지 않았습니다. 외부 바이너리의 라이선스·출처·대응 소스 제공 항목을 해결한 뒤 게시하세요.**

## 추가 기능

- Better Auth 로그인, 초기 관리자 설정, 가입 정책과 초대, 관리자/사용자 역할.
- 개인 음악·이미지·작업·초안과 브라우저 상태의 계정별 분리.
- Windows 도킹·탭·분리 창, 레이아웃과 배경 개인화, 통합 음악 제작 도구.
- 이미지 업로드, 원본/썸네일/화면용 변환, 자르기·내보내기와 표지·배경 연결.
- 별도 데이터 폴더, HTTPS, 최초 설정, 정상 종료·재시작, 임시 데이터 기반 검증 실행기.

## 준비된 파일

| 파일 | 용도 |
|---|---|
| SHS-Music-Studio-v0.1.0-preview-win-x64-cuda.zip | Windows x64 / CUDA 13 Portable 검토 후보 |
| SHS-Music-Studio-v0.1.0-preview-source.zip | 검토한 소스 스냅샷; submodule 내용은 포함하지 않으며 SUBMODULES.json에 고정 커밋 기록 |
| SHA256SUMS.txt | 두 ZIP의 SHA-256 |

Portable ZIP의 `FILE-MANIFEST.json`은 개별 파일 체크섬을 기록합니다(자기 자신 제외). `release-manifest.json`에는 기반 ZIP 해시, 원본 HEAD, 준비한 소스 tree, 런타임·엔진 해시·의존성 목록이 있습니다. 기존 공식 엔진 배포의 바이너리를 재사용했고 서버와 UI는 현재 소스로 다시 빌드했습니다.

## 실행

1. SHA-256을 확인하고 ZIP을 완전히 풉니다.
2. Setup.bat로 별도 데이터 폴더와 HTTPS 주소를 정합니다.
3. SHS-Music-Studio.bat를 실행하고 https://localhost:3443 에 접속합니다(기본 설정).
4. 데이터 폴더의 일회성 bootstrap-token으로 최초 관리자를 만듭니다. 공용 계정·기본 비밀번호는 없습니다.
5. 생성에는 별도로 받은 모델과 호환 GPU 드라이버가 필요합니다.

다른 PC·모바일의 접속, 인증서·역방향 프록시·백업 설정은 README.txt를 참고하세요. 기존 수정판 데이터는 서버를 종료하고 백업한 후 같은 데이터 경로로 연결합니다. 원본 자동 업데이트 대신 SHS ZIP으로 교체하세요.

## 검증과 제한

서버 타입 검사, UI 프로덕션 빌드, 서버 번들 생성과 인증·소유권·이미지·Portable 경로·Workspace 키보드 회귀 검사 17개를 통과했습니다. Verify.bat는 포함된 Node와 임시 데이터로 HTTPS/계정/이미지/재시작/종료를 확인합니다. 상세 실행 결과는 별도 공개 준비 보고서에 기록합니다.

깨끗한 Windows VM, Android 실기기 전체 흐름, 실제 모델 생성·학습과 모든 GPU 조합은 이번 배포 준비에서 검증하지 않았습니다. 외부 보안 감사도 완료하지 않았습니다. 모델·사용자 음악·이미지·DB·세션·개인키·인증서는 배포에 넣지 않습니다. 원본이 배포하는 noise sample과 정적 회귀 fixture는 그대로 유지합니다.

**Release 게시 전 필수 확인:** Essentia, FFmpeg/Sharp의 대응 소스·고지, CUDA/MSVC 재배포 조건, C++ 엔진의 정확한 바이너리 출처. `THIRD_PARTY.md`를 확인하세요. 이 후보 ZIP이 준비되었다는 사실은 해당 조건의 해결을 뜻하지 않습니다.
