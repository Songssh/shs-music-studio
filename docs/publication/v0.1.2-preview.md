# SHS Music Studio v0.1.2-preview

Custom-Gen now has sliders for song count and model-specific Temperature, plus a Random Seed switch. Quick settings and Parameters share the same values, including changes applied through a profile.

- ACE-Step and YuE2 remember independent batch sizes. On first use YuE2 requests one composition. Its estimate multiplies compositions by Noise Variations, so two compositions with two variations produce four expected tracks.
- YuE2 Composer Temperature can follow the checkpoint or accept a manual override. MiniMax-Music3 exposes planner LM Temperature. ACE-Step disables its LM Temperature control when Thinking is off.
- The Custom-Gen header follows the selected backend's model catalogue. Named profiles restore the settings their backend supports. Old profiles retain compatible fields, and shared seed settings remain available across models.

## Windows Portable update

The **UI update ZIP** requires **v0.1.1-preview Windows x64 CUDA Portable**. For a new install, first extract the [base Portable](https://github.com/Songssh/shs-music-studio/releases/tag/v0.1.1-preview). The update uses its existing server and engine.

1. Stop SHS Music Studio. Download `SHS-Music-Studio-v0.1.2-preview-ui-update.zip` and `SHA256SUMS.txt` from this release. Compare the ZIP's SHA-256 using `Get-FileHash .\SHS-Music-Studio-v0.1.2-preview-ui-update.zip -Algorithm SHA256`.
2. In the Portable's `ui` folder, rename `dist` to an unused backup name such as `dist-v0.1.1-backup`. Extract the update ZIP into the Portable folder containing `SHS-Music-Studio.bat`. Check that `ui/dist/index.html` exists there.
3. Start SHS Music Studio and reload the browser. Open Custom-Gen to find Quick generation settings above Generate. The Portable launcher and server retain the base version.

To roll back, stop the app, move the updated `ui/dist` aside, restore the backup folder as `ui/dist`, restart and reload. Setup, account data, models and TLS configuration are separate from the updated folder.

## Source and verification

To build from source, clone the tag with its submodules. The source ZIP contains the tracked project files. Git records the external submodules separately.

```sh
git clone --branch v0.1.2-preview --recurse-submodules https://github.com/Songssh/shs-music-studio.git
```

The release checkout passed 12 focused UI tests, 90 server mapping and resolver tests, the frontend TypeScript check and the Vite production build. GPU audio inference is outside this verification.
